Skill-centric manipulation planning

Plan where skills succeed.

MOSAIC is a family of planners for long-horizon robot manipulation. Rather than growing a plan one step at a time from the start, it lets each skill find the places where it reliably works, connects those pieces into a full plan, and checks every step against a world model.

The paradigm

Skills steer the search.

A long-horizon task, like getting a plate into a bin when it first has to be slid to the table's edge, needs non-obvious intermediate steps. MOSAIC treats skills as active participants in planning, not just actions to try in order.

Generators

Skills such as push, pull and pick propose motions wherever they are likely to work, building up “islands of competence” across the task, without needing to be reached from the start first.

Connectors

Skills that bridge two specific world states, solving the boundary problem between islands so that independent pieces join into one executable plan from start to goal.

World model

Every skill's outcome is predicted by a world model, whether a physics simulator, a learned model, or both, so plans are grounded in physics without hand-written preconditions or effects.

Sequential planners

Grow a plan forward from the start (or back from the goal), so steps that only make sense later, like clearing space first, are hard to find.

MOSAIC

Searches non-sequentially: useful behaviors are found before they connect to a full plan, and effort goes where skills actually succeed.

MOSAIC

Skill-Centric Manipulation Planning with Physics Simulation

The core framework. Generators and connectors search over where skills succeed, with a physics simulator as the world model. It solves long-horizon tasks in simulation and on a real robot using diffusion-model, motion-planning and grasping skills.

Lazy-MOSAIC

Accelerating Skill-Centric Manipulation Planning with Learned Skill-Effect World Models

Adds a cheap learned world model in front of the simulator. The search runs on predicted skill outcomes and simulates only what the plan actually needs.
